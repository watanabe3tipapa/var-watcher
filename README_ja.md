# var-watcher(日本語)

日本語版の README は **[README.md](README.md)** に統合しました。

**var-watcher** は macOS の `/var` をリアルタイムに監視するツールです。`fswatch` /
`watchman` / `entr` / `log stream` の 4 エンジンを TUI と Web UI から一元管理します。
重複排除・SQLite 永続化(時系列/キーワード検索)・ルールベース アラートに対応。

新機能や設定例は README.md を参照してください。
